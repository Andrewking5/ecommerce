## 📸 拍攝建議

### 器材
- 相機：手機即可（iPhone/Android 旗艦），或單眼更佳
- 光線：**自然光最好**（窗邊，陰天柔光），避免直射造成反光
- 背景：白色或淺灰紙/布（去背用），木紋特寫不需要背景

### 拍攝技巧
- **木紋特寫**：距離 15-20cm，對焦在紋理上，光線從側面打（凸顯立體感）
- **琴身整體**：距離 1-1.5m，琴身放正，光線均勻
- **細節特寫**：距離 5-10cm，手動對焦在目標部件上
- **避免**：手指入鏡、灰塵、指紋、過曝/過暗

### 檔案格式
- JPG 或 PNG 皆可
- 解析度越高越好（我會處理壓縮和裁切）
- 命名建議：`{部件}_{材質}_{角度}.jpg`
  - 例：`top_sitka-spruce_grain.jpg`
  - 例：`body_ga_cutaway_front.jpg`
  - 例：`tuner_gold_closeup.jpg`

## ⚡ 優先順序（先拍這些就能上線）

### 第一批（最少可上線版本）— 約 25 張
```
□ 各桶身正面照 × 5（D/GA/OM/Parlor/SJ）
□ 面板木紋特寫 × 3（Sitka / Cedar / Mahogany）
□ 背板木紋特寫 × 3（Rosewood / Mahogany / Koa）
□ 指板特寫 × 2（Rosewood / Ebony）
□ 鑲嵌特寫 × 3（Dot / Abalone / MOP）
□ 弦鈕特寫 × 3（Chrome / Gold / Black）
□ 漆面對比 × 2（Gloss / Satin）
□ 音孔環特寫 × 2（Standard / Abalone）
□ 琴袋/琴盒 × 2
```

### 第二批（完整版）— 補齊剩下的所有項目

### 第三批（豪華版）— 加拍：
```
□ 各桶身大小對比並排照
□ 360° 轉盤照（每 15° 拍一張 = 24 張/把）
□ 使用情境照（演奏、工坊）
□ 影片：木材敲擊聽音色差異
```
